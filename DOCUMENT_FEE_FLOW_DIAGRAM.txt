SPECIAL CASES:
-------------

Case 1: FREE DOCUMENT (Fee = ₱0)
┌─────────────────────────────────────────────────────────────┐
│ Owner sets "Good Moral" fee to ₱0.00                        │
│ Student requests "Good Moral"                                │
│ Registrar approves                                           │
│ ❌ NO balance created (fee is ₱0)                           │
│ ✅ Document can be claimed immediately                      │
└─────────────────────────────────────────────────────────────┘

Case 2: DECLINED REQUEST
┌─────────────────────────────────────────────────────────────┐
│ Student requests document                                    │
│ Registrar declines (Status: "Declined")                     │
│ ❌ NO balance created                                        │
│ ✅ No unnecessary charges                                   │
└─────────────────────────────────────────────────────────────┘

Case 3: MULTIPLE REQUESTS
┌─────────────────────────────────────────────────────────────┐
│ Student requests "Form137" (1st time)                       │
│ Registrar approves → Balance created: ₱50.00                │
│ Student requests "Form137" again (2nd time)                 │
│ Registrar approves → Another balance created: ₱50.00        │
│ Total balance: ₱100.00 (2 separate fees)                    │
└─────────────────────────────────────────────────────────────┘

                    If > 0: Create entry in student_fee_items


KEY POINTS:
----------
✅ Balance created ONLY when Registrar approves
✅ Uses student_fee_items table (Cashier's table)
✅ Free documents (₱0) never create balances
✅ Each approval creates a separate balance
✅ School year term automatically determined
✅ Cashier sees balances immediately

This is the complete flow! 🎉
