THE PROBLEM:
------------
Error: "Unexpected token '<', '<br /><b>'... is not valid JSON"

This happened when trying to add a new school year (2025-2026).
The error means PHP returned HTML error instead of JSON.

ROOT CAUSE:
-----------
Database has a UNIQUE constraint on (grade_level, academic_track, school_year, term)
When trying to create records that already exist, it fails with duplicate key error.

THE FIX:
--------
Updated OwnerF/ManageTuitionFees.php to:

1. Use INSERT IGNORE instead of INSERT
   - Automatically skips duplicates
   - No error thrown
   - Continues with other records

2. Added try-catch error handling
   - Catches any exceptions
   - Returns proper JSON error message
   - No more HTML errors

3. Removed redundant duplicate checking
   - INSERT IGNORE handles it automatically
   - Faster execution
   - Cleaner code

WHAT CHANGED:
-------------
OLD CODE:
- Check if record exists (SELECT query)
- If not exists, INSERT
- If exists, skip
- Problem: Race conditions, slower

NEW CODE:
- INSERT IGNORE (single query)
- Database handles duplicates automatically
- Faster and safer
