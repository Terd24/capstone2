HOW TO USE (STEP BY STEP):
--------------------------

STEP 1: SET DOCUMENT FEES (Owner)
----------------------------------
1. Login as Owner
2. Go to: http://localhost/onecci/OwnerF/Dashboard.php
3. Click "Document Fees" in left sidebar
4. Click "Edit Fee" for any document
5. Enter amount:
   - ₱0 = Free (no balance created)
   - > ₱0 = Paid (balance created when approved)
6. Click "Save Fee"

Example: Set "Form137" to ₱50.00

STEP 2: STUDENT REQUESTS DOCUMENT
----------------------------------
1. Student logs in
2. Goes to "Request Document"
3. Selects "Form137"
4. Enters purpose
5. Submits request
6. Status: "Pending"
7. NO BALANCE CREATED YET ✓

STEP 3: REGISTRAR APPROVES REQUEST
-----------------------------------
1. Registrar logs in
2. Goes to Student Documents
3. Finds the student's request
4. Changes status from "Pending" to "Approved"
5. BALANCE AUTOMATICALLY CREATED ✓

STEP 4: CASHIER SEES BALANCE
-----------------------------
1. Cashier logs in
2. Searches for student (by name or RFID)
3. Sees: "Document Request Fee - Form137: ₱50.00"
4. Student pays ₱50.00
5. Cashier marks as paid

STEP 5: DOCUMENT READY
-----------------------
1. Registrar marks as "Ready to Claim"
2. Student claims document
3. Status: "Claimed"

TESTING CHECKLIST:

VERIFICATION QUERIES:
--------------------
Run these in phpMyAdmin to verify:

1. Check document fees:
   SELECT * FROM document_fees WHERE is_active = 1;

2. Check recent requests:
   SELECT * FROM document_requests ORDER BY date_requested DESC LIMIT 5;

3. Check balances created:
   SELECT * FROM student_fee_items 
   WHERE fee_type LIKE '%Document Request Fee%' 
   ORDER BY date_added DESC;

Or run the complete verification script:
- Open phpMyAdmin
- Select onecci_db
- Run: verify_document_fees.sql

TROUBLESHOOTING:
---------------
Q: Balance not showing in Cashier?
A: 1. Check if Registrar approved the request (not just pending)
   2. Check if fee amount > ₱0 in Owner Dashboard
   3. Run verification queries above

Q: Form137 still not showing?
A: 1. Make sure you APPROVED the request (not just requested)
   2. Check student_fee_items table in database
   3. Refresh Cashier page

Q: Multiple balances for same document?
A: This is normal - each approval creates a new balance
   Student must pay each one separately
