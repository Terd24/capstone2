THE PROBLEM:
------------
When you filter by "2nd Semester", it shows "0 fee structures"
This means your existing school years only have 1st Semester records.

THE SOLUTION:
-------------
Run a SQL script to automatically create 2nd Semester records
by copying from 1st Semester records.

HOW TO FIX:
-----------

STEP 1: Open phpMyAdmin
   - Go to: http://localhost/phpmyadmin
   - Select your database

STEP 2: Run the SQL Script
   - Click "SQL" tab
   - Open file: add_missing_2nd_semester.sql
   - Copy ALL content (Ctrl+A, Ctrl+C)
   - Paste into SQL box (Ctrl+V)
   - Click "Go" button

STEP 3: Verify Results
   - Go to Owner Dashboard → Tuition Fees
   - Filter by "2nd Semester"
   - You should now see all grade levels!

WHAT IT DOES:
-------------

1. Shows current records by semester
2. Identifies school years missing 2nd semester
3. Copies all 1st Semester records
4. Creates 2nd Semester versions with same prices
5. Shows verification results

BEFORE:
-------
School Year: 2025-2026
├── 1st Semester: 34 records ✓
└── 2nd Semester: 0 records ✗

AFTER:
------
School Year: 2025-2026
├── 1st Semester: 34 records ✓
└── 2nd Semester: 34 records ✓

WHAT YOU'LL SEE:
----------------

After running the script:

2025-2026    | 1st Semester  | 34

IMPORTANT NOTES:

✓ You can edit 2nd Semester prices later
✓ All grade levels included (Kinder 1 to 4th Year)
✓ Works for all existing school years

AFTER RUNNING:
--------------

1. Refresh your Owner Dashboard
2. Go to Tuition Fees section
3. Expand any school year
4. Filter by "2nd Semester"
5. You should see:
   - Kinder 1
