🔄 HOW THE APPROVAL SYSTEM WORKS:

Step 1: SUPERADMIN REQUESTS
   - SuperAdmin wants to archive/clear/delete something
   - Clicks the action button (Archive, Clear Logs, etc.)
   - Provides reason for the action
   - System creates approval request

Step 2: OWNER REVIEWS
   - Owner logs into Owner Dashboard
   - Sees pending approval requests
   - Reviews request details and reason
   - Can approve or reject with comments

Step 3: AUTOMATIC EXECUTION
   - If approved: System automatically executes the action
   - If rejected: No action taken, SuperAdmin is notified

═══════════════════════════════════════════════════════════════════

📋 ACTIONS REQUIRING APPROVAL:

1. Archive Student
   - SuperAdmin → View Deleted Records → Archive
   - Owner approves → Student moved to archived_students table

2. Archive Employee
   - SuperAdmin → View Deleted Records → Archive
   - Owner approves → Employee moved to archived_employees table

3. Clear Login Logs
   - SuperAdmin → System Maintenance → Clear Login Logs
   - Provide date range and reason
   - Owner approves → Logs archived and cleared

4. Clear Attendance Records
   - SuperAdmin → System Maintenance → Clear Attendance
   - Provide date range and reason
   - Owner approves → Attendance archived and cleared

5. Restore Deleted Records
   - SuperAdmin → View Deleted Records → Restore
   - Owner approves → Record restored to active

6. Add/Delete HR Employees
   - SuperAdmin → HR Management → Add/Delete
   - Owner approves → Action executed
