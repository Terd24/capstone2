✅ DOCUMENT REQUEST FEE SYSTEM - FIX APPLIED
============================================

ISSUE REPORTED:
--------------
1. Balance was not showing in Cashier system
2. Form137 fee was set but no balance appeared
3. User wanted balance to be created when Registrar APPROVES, not when student requests

PROBLEMS IDENTIFIED:
-------------------
1. Balance was being created at REQUEST time (wrong timing)
2. Balance was being created in wrong table (student_balances instead of student_fee_items)
3. Cashier system uses student_fee_items table, not student_balances

FIXES APPLIED:
-------------
1. REMOVED balance creation from request stage:
   - StudentLogin/request-document.php
   - ParentLogin/ParentDocumentRequest.php
   
2. ADDED balance creation to approval stage:
   - RegistrarF/update_document_status.php
   - Balance now created when status changes to "Approved"

3. FIXED table usage:
   - includes/create_document_balance.php
   - Changed from student_balances to student_fee_items
   - Added school_year_term field (required by Cashier)
   - Uses latest term from student's existing fees
   - Falls back to current school year if no existing fees

NEW WORKFLOW:
------------
1. Student requests document → Status: "Pending" → NO balance created
2. Registrar approves → Status: "Approved" → Balance created automatically
3. Cashier sees balance → Student pays
4. Registrar marks "Ready to Claim" → Student claims

WHY THIS IS BETTER:
------------------
✅ Balance only created for approved requests
✅ No unnecessary balances for declined requests
✅ Registrar has control over when fees are charged
✅ Uses correct table (student_fee_items) that Cashier reads
✅ Includes school_year_term for proper organization
✅ Integrates seamlessly with existing Cashier system

TECHNICAL CHANGES:
-----------------
File: includes/create_document_balance.php

- Added school_year_term logic
- Added paid field (starts at 0)
- Removed status field (not used in student_fee_items)

File: RegistrarF/update_document_status.php

Files: StudentLogin/request-document.php & ParentLogin/ParentDocumentRequest.php
