🚀 HOW TO CREATE DEPARTMENT HEAD ACCOUNT:
═══════════════════════════════════════════════════════════════════════

METHOD 1: Using HR Dashboard (Recommended for HR Staff)
────────────────────────────────────────────────────────
1. Login as HR Admin
2. Go to HRF/Dashboard.php
3. Click "Add Employee" or create account for existing employee
4. Select "Department Head" from Role dropdown
5. Complete the form and submit

METHOD 2: Using Super Admin Dashboard (For Super Admin)
────────────────────────────────────────────────────────
1. Login as Super Admin
2. Go to AdminF/SuperAdminDashboard.php
3. Navigate to HR Accounts section
4. Click "Create Account"
5. Select "Department Head" from Role dropdown
6. Complete the form and submit

Session Variables:

• teacher_sections - Section assignments
• teacher_attendance - Attendance records
