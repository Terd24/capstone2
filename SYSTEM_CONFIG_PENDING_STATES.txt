SYSTEM CONFIGURATION - PENDING STATES IMPLEMENTATION
===================================================

FEATURE COMPLETE:
-----------------
Added visual pending states for Maintenance Mode and Database Backup requests.

NEW FILE CREATED:
-----------------
AdminF/check_system_config_status.php
- Checks for pending maintenance mode toggle requests
- Checks for pending database backup requests
- Returns current maintenance mode status
- Polls every 2 seconds

VISUAL INDICATORS:
------------------

MAINTENANCE MODE:
1. When Request Submitted:
   ✓ Toggle becomes grey/disabled (shows pending state)
   ✓ Toggle shows the REQUESTED state (ON if enabling, OFF if disabling)
   ✓ "Update Configuration" button disabled and grey
   ✓ Shows: "⏳ Request pending approval from Owner"

2. When Owner Approves:
   ✓ Toggle automatically updates to approved state
   ✓ Toggle re-enables (no longer grey)
   ✓ Button re-enables
   ✓ Pending message disappears
   ✓ System enters/exits maintenance mode

3. When Owner Rejects:
   ✓ Toggle reverts to previous state
   ✓ Toggle re-enables
   ✓ Button re-enables
   ✓ Pending message disappears

DATABASE BACKUP:
1. When Request Submitted:
   ✓ "Download Database Backup" button disabled and grey
   ✓ Shows: "⏳ Request pending approval from Owner"

2. When Owner Approves:
   ✓ Button automatically re-enables
   ✓ Pending message disappears
   ✓ Backup file created in /backups/ directory

3. When Owner Rejects:
   ✓ Button re-enables
   ✓ Pending message disappears

AUTO-POLLING:
-------------
- Checks status every 2 seconds
- Updates UI automatically
- No page refresh needed
- Real-time feedback

USER EXPERIENCE:
----------------
1. SuperAdmin toggles maintenance mode ON
2. Clicks "Update Configuration"
3. Enters reason and submits
4. Toggle becomes grey and shows ON (pending state)
5. Button disabled with pending message
6. Owner approves in their dashboard
7. Within 2 seconds:
   - Toggle becomes active (no longer grey)
   - Toggle stays ON (approved state)
   - Button re-enables
   - Pending message disappears
   - Maintenance mode is now active

TECHNICAL DETAILS:
------------------
- Uses localStorage to persist pending states
- Polls check_system_config_status.php every 2 seconds
- Updates button states dynamically
- Updates toggle states dynamically
- Handles both enable and disable requests
- Synchronizes with actual system state

BENEFITS:
---------
✓ Clear visual feedback
✓ User knows request is pending
✓ Automatic updates when approved
✓ No manual refresh needed
✓ Toggle shows intended state while pending
✓ Grey toggle indicates "waiting for approval"
✓ Consistent with archive system behavior
