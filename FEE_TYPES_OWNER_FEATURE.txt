✅ FEE TYPES MANAGEMENT - OWNER DASHBOARD
==========================================

WHAT WAS ADDED:
--------------
The Owner can now manage fee types (like Library Fee, Laboratory Fee, etc.) 
directly from their dashboard at: http://localhost/onecci/OwnerF/Dashboard.php

NEW FILES CREATED:
-----------------
1. OwnerF/ManageFeeTypes.php
   - Backend API for managing fee types
   - Handles GET (fetch all fee types) and POST (add/edit/delete)
   - Auto-creates 'fee_types' table if it doesn't exist
   - Uses soft delete (is_active flag)

CHANGES TO EXISTING FILES:
-------------------------
1. OwnerF/Dashboard.php
   - Added "Fee Types" navigation menu item
   - Added Fee Types section with table display
   - Added JavaScript functions:
     * loadFeeTypes() - Fetches and displays fee types
     * displayFeeTypes() - Renders fee types table
     * showAddFeeTypeModal() - Shows add modal
     * editFeeType() - Shows edit modal
     * saveFeeType() - Saves add/edit
     * deleteFeeType() - Soft deletes fee type
     * closeFeeTypeModal() - Closes modal
     * showNotification() - Shows success/error messages

DATABASE TABLE:
--------------
Table: fee_types
Columns:
  - id (INT, AUTO_INCREMENT, PRIMARY KEY)
  - fee_name (VARCHAR(100), UNIQUE, NOT NULL)
  - default_amount (DECIMAL(10,2), DEFAULT 0.00)
  - is_active (BOOLEAN, DEFAULT TRUE)
  - created_at (TIMESTAMP)
  - updated_at (TIMESTAMP)

FEATURES:
--------
✅ View all active fee types in a table
✅ Add new fee types with name and default amount
✅ Edit existing fee types
✅ Delete fee types (soft delete)
✅ Automatic table creation on first use
✅ Input validation (required fields, non-negative amounts)
✅ Duplicate name prevention
✅ Success/error notifications
✅ Responsive design

HOW TO USE:
----------
1. Login as Owner at: http://localhost/onecci/OwnerF/Dashboard.php
2. Click "Fee Types" in the left sidebar
3. Click "+ Add Fee Type" to create new fee types
4. Enter fee name (e.g., "Library Fee") and default amount
5. Edit or delete existing fee types using the action buttons

INTEGRATION:
-----------
The fee types created here can be used by the Cashier when adding fees
to student accounts. The default amounts serve as suggested values that
can be customized per student.

NOTES:
-----
- Only the Owner role can access this feature
- Fee types are soft-deleted (marked inactive) not permanently removed
- The table auto-creates on first access
- All amounts are stored as DECIMAL(10,2) for precision
