🔍 DEBUG DOCUMENT BALANCE ISSUE
================================

PROBLEM: Balance not showing in Cashier after approval

DEBUGGING STEPS:
---------------

STEP 1: Run Debug Script
------------------------
1. Open browser and go to:
   http://localhost/onecci/debug_document_balance.php

2. This will show you:
   - Document fees configuration
   - Recent document requests
   - Balances created in student_fee_items
   - Specific student data
   - Test balance creation

3. Look for:
   ✅ Document fees are configured (Form137 = ₱50.00 or whatever you set)
   ✅ Document requests exist with status "Approved"
   ❌ If no balances in student_fee_items, there's a problem

STEP 2: Run Manual Test
-----------------------
1. Open browser and go to:
   http://localhost/onecci/test_create_balance.php

2. Edit the file first to set:
   $test_student_id = '02200000001';  // Your student ID
   $test_document_type = 'Form137';    // Your document type

3. Run the script and check each step:
   - Step 1: Document fee should be found
   - Step 2: Student should be found
   - Step 3: Shows existing fee items
   - Step 4: Creates the balance
   - Step 5: Verifies balance was created
   - Step 6: Shows all fee items

STEP 3: Check PHP Error Log
---------------------------
1. Open: C:\xampp\php\logs\php_error_log (Windows)
   Or: /var/log/php_error.log (Linux)

2. Look for lines with:
   "=== CREATE DOCUMENT BALANCE START ==="
   "=== DOCUMENT APPROVED - CREATING BALANCE ==="

3. Check if there are any errors

STEP 4: Check Database Directly
-------------------------------
1. Open phpMyAdmin
2. Select onecci_db database
3. Run these queries:

-- Check document fees
SELECT * FROM document_fees WHERE is_active = 1;

-- Check document requests
SELECT * FROM document_requests 
WHERE status = 'Approved' 
ORDER BY date_requested DESC 
LIMIT 5;

-- Check if balances were created
SELECT * FROM student_fee_items 
WHERE fee_type LIKE '%Document Request Fee%' 
ORDER BY date_added DESC;

-- Check specific student
SELECT * FROM student_fee_items 
WHERE id_number = '02200000001';

COMMON ISSUES & FIXES:
---------------------

ISSUE 1: Document fee not configured
FIX: Go to Owner Dashboard → Document Fees → Set fee for Form137

ISSUE 2: Document name mismatch
FIX: Make sure document name in document_fees exactly matches 
     the document_type in document_requests (case-sensitive!)

ISSUE 3: Status not "Approved"
FIX: Make sure Registrar changed status to exactly "Approved"
     (not "approved" or "APPROVED")

ISSUE 4: Function not being called
FIX: Check PHP error log for errors in update_document_status.php

ISSUE 5: School year term mismatch
FIX: Check what term the Cashier is looking for vs what was created

ISSUE 6: Table doesn't exist
FIX: Run this SQL:
CREATE TABLE IF NOT EXISTS student_fee_items (
    id INT AUTO_INCREMENT PRIMARY KEY,
    id_number VARCHAR(50),
    student_name VARCHAR(200),
    grade_level VARCHAR(50),
    school_year_term VARCHAR(50),
    fee_type VARCHAR(200),
    amount DECIMAL(10,2),
    paid DECIMAL(10,2) DEFAULT 0,
    date_added TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
