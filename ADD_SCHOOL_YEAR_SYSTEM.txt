ADD SCHOOL YEAR SYSTEM - SIMPLIFIED
=====================================

OVERVIEW:
---------
Owner simply adds a school year (e.g., "2025-2026"), and the system automatically
creates ALL possible grade levels, tracks, and terms with ₱0.00 fees.

No more manual adding of individual fee structures!

HOW IT WORKS:
-------------

STEP 1: Owner Clicks "+ Add School Year"
-----------------------------------------
- Button located in Owner Dashboard → Tuition Fees
- Opens a simple modal with one input field

STEP 2: Enter School Year
--------------------------
- Format: YYYY-YYYY (e.g., 2025-2026)
- Click "Create School Year"

STEP 3: System Auto-Creates Everything
---------------------------------------
System automatically creates 66 fee structures:

PRE-ELEMENTARY (2 structures):
- Kinder - 1st Semester = ₱0.00
- Kinder - 2nd Semester = ₱0.00

ELEMENTARY (12 structures):
- Grade 1-6 × 2 semesters = ₱0.00

JUNIOR HIGH SCHOOL (8 structures):
- Grade 7-10 × 2 semesters = ₱0.00

SENIOR HIGH SCHOOL (28 structures):
- Grade 11-12 × 7 strands (ABM, GAS, HUMSS, STEM, ICT, HE, SPORTS) × 2 semesters = ₱0.00

COLLEGE (16 structures):
- 1st-4th Year × 2 courses (BPed, BECEd) × 2 semesters = ₱0.00

TOTAL: 66 fee structures per school year

STEP 4: Owner Edits Prices
---------------------------
- All fees now visible with ₱0.00
- Owner clicks edit button on each card
- Updates tuition fee and other fees
- Saves changes

EXAMPLE WORKFLOW:
-----------------

SCENARIO: Owner wants to add fees for 2026-2027

OLD WAY (Manual):
1. Click "+ Add New Fee Structure"
2. Enter: Kinder, Pre-Elementary, ₱26000, ₱5200, 2026-2027, 1st Semester
3. Click Add
4. Repeat 65 more times for all combinations
5. Total time: ~30 minutes

NEW WAY (Automatic):
1. Click "+ Add School Year"
2. Enter: 2026-2027
3. Click "Create School Year"
4. Done! All 66 structures created in seconds
5. Just edit the prices
6. Total time: ~2 minutes

BENEFITS:
---------
✅ One-click school year creation

✅ Consistent structure across years

WHAT GETS AUTO-CREATED:
-----------------------
For each school year, system creates:

1 Kinder
6 Elementary grades
4 JHS grades
14 SHS (7 strands × 2 grades)
8 College (2 courses × 4 years)
= 33 grade/track combinations

× 2 terms (1st & 2nd Semester)
= 66 total fee structures

All with:
- Tuition Fee: ₱0.00
- Other Fees: ₱0.00
- Total Fee: ₱0.00

DUPLICATE PREVENTION:
---------------------
✓ System checks if combination already exists
✓ Skips existing records
✓ Only creates missing combinations
✓ Safe to run multiple times

ADDING MULTIPLE YEARS:
----------------------
Want to add 3 years at once?

1. Add 2025-2026 → Creates 66 structures
2. Add 2026-2027 → Creates 66 structures
3. Add 2027-2028 → Creates 66 structures
Total: 198 structures in minutes!

EDITING PRICES:
---------------
After adding school year:

1. Go to Owner Dashboard → Tuition Fees
2. Expand school year (e.g., 2026-2027)
3. Filter by term if needed
4. See all grades with ₱0.00
5. Click edit on each card
6. Update prices:
   - Kinder, 1st Semester → ₱26,000
   - Kinder, 2nd Semester → ₱26,000
   - Grade 1, 1st Semester → ₱29,000
   - etc.
