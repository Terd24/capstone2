✅ INSTANT URL CLEANUP - ZERO FLASH IMPLEMENTATION
==================================================

PROBLEM SOLVED:
--------------
Previously, query parameters (?student_id=...&type=...) were visible for 
~0.5 seconds before JavaScript could hide them. Now they NEVER appear!

SOLUTION:
--------
Server-side session-based approach with immediate redirect BEFORE any 
HTML is rendered to the browser.

HOW IT WORKS:
------------
1. User clicks link: ViewStudentInfo.php?student_id=02200000005&type=requested
2. PHP immediately (line 6-11):
   - Stores student_id in $_SESSION['view_student_id']
   - Stores type in $_SESSION['view_doc_type']
   - Sends HTTP redirect header to ViewStudentInfo.php (clean URL)
   - Exits before rendering ANY HTML
3. Browser receives redirect and loads clean URL
4. Clean URL page loads data from session
5. User NEVER sees the parameters!

Code Flow:
----------
INITIAL LOAD:
  URL with params → Check params → Store in session → Redirect → Load from session
