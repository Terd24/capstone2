🚀 QUICK START - DOCUMENT REQUEST FEE SYSTEM
=============================================

WHAT WAS BUILT:
--------------
A complete system where the Owner can set fees for document requests,
and when students request documents, balances are automatically created
in the Cashier system (only if fee > ₱0).

HOW TO USE:
----------

STEP 1: SETUP (One-time)
------------------------
1. The document_fees table will be created automatically when you first
   access the Document Fees section
   
   OR run this SQL manually:
   - Open phpMyAdmin
   - Select onecci_db database
   - Run: setup_document_fees.sql

STEP 2: SET DOCUMENT FEES (Owner)
---------------------------------
1. Login as Owner: http://localhost/onecci/OwnerF/Dashboard.php
2. Click "Document Fees" in the left sidebar
3. You'll see a list of all requestable documents
4. Click "Edit Fee" for any document
5. Enter the fee amount:
   - ₱0 = Free (no balance created)
   - > ₱0 = Paid (balance created automatically)
6. Click "Save Fee"

STEP 3: TEST THE SYSTEM
-----------------------
1. As Owner, set a fee (e.g., "Form 137" = ₱50.00)
2. Login as Student
3. Request "Form 137" document (Status: Pending)
4. Login as Registrar
5. Go to Student Documents and change status to "Approved"
6. Check Cashier system - you should see a ₱50.00 balance!

STEP 4: PROCESS PAYMENT (Cashier)
---------------------------------
1. Login as Cashier
2. Search for the student
3. You'll see: "Document Request Fee - Form 137: ₱50.00"
4. Process payment normally
5. Mark as paid

FEATURES AT A GLANCE:
--------------------
✅ Owner sets fees for each document type
✅ ₱0 = Free (no balance created)
✅ > ₱0 = Automatic balance creation
✅ Works for student AND parent requests
✅ Integrates with existing Cashier system
✅ Visual indicators (green badge = creates balance)
✅ No manual work needed

EXAMPLE WORKFLOW:
----------------
Owner: Sets "Transcript of Records" fee to ₱100.00
↓
Student: Requests "Transcript of Records" (Status: Pending)
↓
Registrar: Approves request (Status: Approved)
↓
System: Automatically creates ₱100.00 balance
↓
Cashier: Sees balance, collects payment
↓
Registrar: Marks as "Ready to Claim"
↓
Student: Claims document

IMPORTANT NOTES:
---------------
- Document types must exist in Registrar Dashboard first
- Only "requestable" documents appear in the list
- Each request creates a separate balance
- Free documents (₱0) don't create balances
- Balances appear immediately in Cashier system

TROUBLESHOOTING:
---------------
Q: No documents showing in Document Fees?
A: Add document types in Registrar Dashboard first
   (Make sure "is_requestable" is checked)

Q: Balance not appearing in Cashier?
A: Check that fee amount is > ₱0
   Check student_balances table in database

Q: Can't edit fees?
A: Make sure you're logged in as Owner
   Check browser console for errors
