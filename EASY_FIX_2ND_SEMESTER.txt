OPTION 1: Run PHP Script (EASIEST - Recommended)

4. Done! ✓

OPTION 2: Run SQL in phpMyAdmin
--------------------------------

6. Paste and click "Go"
7. Done! ✓

HOW IT WORKS WITH REGISTRAR:
-----------------------------

When Registrar creates a student account:
1. Selects school year (e.g., 2025-2026)
2. Selects term (1st Semester or 2nd Semester)
3. System automatically assigns correct tuition fee

Example:
- Student: John Doe
- Grade: Kinder 1
- School Year: 2025-2026
- Term: 2nd Semester
→ System finds: Kinder 1 + 2025-2026 + 2nd Semester
→ Assigns that tuition fee to student
