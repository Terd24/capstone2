✅ Archive Login Logs - Fixed!

Data type issue resolved

The archive login logs approval is now working!

Fixed bind_param data type mismatch for session_duration.

🔧 What Was Fixed

❌ Issue:

bind_param type string was: 'issssissssss'

session_duration is an INTEGER, not a STRING

This caused the archive to fail silently

✅ Fix:

Changed bind_param type to: 'isssssisssss'

Now session_duration is correctly typed as integer (i)

Archive now works correctly!
