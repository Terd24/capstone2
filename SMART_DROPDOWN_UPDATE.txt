✅ SMART DROPDOWN WITH AUTO-UPDATE
===================================

FEATURES:
--------
1. ✅ All status options always visible
2. ✅ Invalid options shown in GRAY (disabled)
3. ✅ Automatic dropdown update after status change (NO REFRESH!)
4. ✅ Smooth workflow progression

HOW IT WORKS:
------------

VISUAL EXAMPLE:
--------------

When status is "Pending":
┌─────────────────────────┐
│ Pending (selected)      │ ← Black (current)
│ Approved                │ ← Black (clickable)
│ Ready to Claim          │ ← Gray (disabled)
│ Claimed                 │ ← Gray (disabled)
│ Declined                │ ← Black (clickable)
└─────────────────────────┘

After clicking "Approved":
┌─────────────────────────┐
│ Pending                 │ ← Gray (disabled)
│ Approved (selected)     │ ← Black (current)
│ Ready to Claim          │ ← Black (clickable)
│ Claimed                 │ ← Gray (disabled)
│ Declined                │ ← Gray (disabled)
└─────────────────────────┘
↑ Dropdown updates automatically!

After clicking "Ready to Claim":
┌─────────────────────────┐
│ Pending                 │ ← Gray (disabled)
│ Approved                │ ← Gray (disabled)
│ Ready to Claim (sel.)   │ ← Black (current)
│ Claimed                 │ ← Black (clickable)
│ Declined                │ ← Gray (disabled)
└─────────────────────────┘
↑ Dropdown updates automatically!

After clicking "Claimed":
┌─────────────────────────┐
│ Pending                 │ ← Gray (disabled)
│ Approved                │ ← Gray (disabled)
│ Ready to Claim          │ ← Gray (disabled)
│ Claimed (selected)      │ ← Black (current)
│ Declined                │ ← Gray (disabled)
└─────────────────────────┘
↑ Entire dropdown is DISABLED (final state)

WORKFLOW RULES:
--------------

Status: Pending
├─ Clickable: Approved, Declined
└─ Grayed out: Ready to Claim, Claimed

Status: Approved
├─ Clickable: Ready to Claim
└─ Grayed out: Pending, Claimed, Declined

Status: Ready to Claim
├─ Clickable: Claimed
└─ Grayed out: Pending, Approved, Declined

Status: Claimed
├─ Clickable: None (dropdown disabled)
└─ Grayed out: All others

Status: Declined
├─ Clickable: None (dropdown disabled)
└─ Grayed out: All others

TECHNICAL IMPLEMENTATION:
------------------------

1. PHP Side (ViewStudentInfo.php):
   - Generates dropdown with all 5 options
   - Disables invalid options based on current status
   - Adds gray styling to disabled options

2. JavaScript Side (updateStatusSmart function):
   - Sends AJAX request to update status
   - Waits for server response
   - Rebuilds dropdown options based on new status
   - Applies gray styling to invalid options
   - Disables dropdown if final state reached

3. No Page Refresh:
   - Uses fetch() API for AJAX
   - Updates DOM directly
   - Smooth user experience
