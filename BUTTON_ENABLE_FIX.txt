BUTTON RE-ENABLE FIX
====================

PROBLEM:
--------
After Owner approved the archive request, the button remained disabled 
and showed "Request pending approval from Owner" for 5 minutes.

ROOT CAUSE:
-----------
The check_archive_status.php was checking for:
- status = 'pending' OR
- status = 'approved' AND reviewed within last 5 minutes

This kept the button disabled for 5 minutes after approval.

FIX APPLIED:
------------
Changed the query to ONLY check for status = 'pending'

BEFORE:
AND (
    status = 'pending' 
    OR (status = 'approved' AND reviewed_at > DATE_SUB(NOW(), INTERVAL 5 MINUTE))
)

AFTER:
AND status = 'pending'

RESULT:
-------
✓ Button stays disabled ONLY while request is actually pending
✓ Once Owner approves/rejects, button re-enables within 2 seconds
✓ Notification still shows (within 10 seconds of approval/rejection)
✓ User can immediately submit a new request after approval

TESTING:
--------
1. Submit archive request → Button disables, shows "pending" message
2. Owner approves request → Within 2 seconds:
   - Notification appears
   - Button re-enables
   - "Pending" message disappears
3. Can immediately submit another request
