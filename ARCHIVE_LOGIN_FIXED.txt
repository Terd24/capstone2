🔧 WHAT WAS FIXED:

The archive login logs approval was failing due to a data type mismatch
in the bind_param function.

ISSUE:
   - bind_param type string was: 'issssissssss'
   - session_duration is an INTEGER, not a STRING
   - This caused the archive to fail silently

FIX:
   - Changed bind_param type to: 'isssssisssss'
   - Now session_duration is correctly typed as integer (i)
   - Archive now works correctly!

📊 HOW IT WORKS:

1. SuperAdmin requests to clear login logs
2. System creates approval request in owner_approval_requests table
3. Owner reviews and approves the request
4. System automatically:
   - Creates login_logs_archive table (if not exists)
   - Copies all matching login records to archive
   - Deletes original records from login_activity table
   - Logs the action

   - owner_approval_requests (approval requests)
