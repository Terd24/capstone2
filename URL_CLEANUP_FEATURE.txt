✅ URL CLEANUP - COMPLETELY HIDE QUERY PARAMETERS
=================================================

WHAT WAS CHANGED:
----------------
The URL query parameters (student_id and type) are now COMPLETELY hidden 
from the browser address bar using a session-based approach. The URL is 
clean from the very first moment - no flashing of parameters!

FILE MODIFIED:
-------------
RegistrarF/ViewStudentInfo.php

CHANGES MADE:
------------
1. Implemented session-based storage for student_id and document type
2. Automatic redirect from URLs with parameters to clean URL
3. The URL ALWAYS shows: http://localhost/onecci/RegistrarF/ViewStudentInfo.php
4. Never shows: http://localhost/onecci/RegistrarF/ViewStudentInfo.php?student_id=02200000005&type=requested

HOW IT WORKS:
------------
SERVER-SIDE APPROACH (No JavaScript delays):
1. When URL has parameters (?student_id=...&type=...), PHP immediately:
   - Stores values in $_SESSION['view_student_id'] and $_SESSION['view_doc_type']
   - Redirects to clean URL (ViewStudentInfo.php) with header()
   - This happens BEFORE any HTML is rendered
2. Clean URL loads and reads data from session
3. All subsequent operations (add, delete, tab switch) use session storage
4. Tab switching uses POST method to update session, then redirects to clean URL

BENEFITS:
--------
✅ URL is clean from the very first moment (no 0.5 second flash)
✅ Completely hides sensitive student ID
✅ More secure - parameters never visible in browser
✅ Professional appearance
✅ Works without JavaScript
✅ No browser history pollution with parameter URLs

TECHNICAL DETAILS:
-----------------
Session Storage:
  $_SESSION['view_student_id'] - Stores current student ID
  $_SESSION['view_doc_type'] - Stores current tab (requested/submitted)

Redirect Flow:
  URL with params → Store in session → Redirect to clean URL → Load from session

Tab Switching:
  Uses POST form submission to update session, then redirects to clean URL

COMPATIBILITY:
-------------
✅ Works on ALL browsers (server-side solution)

SECURITY:
--------
✅ Student IDs never appear in URL

NOTE:
----
The student data is stored in PHP session ($_SESSION) which is:
- Server-side (more secure than URL parameters)
- Persistent across page loads
- Automatically cleaned when session ends
- Not visible in browser address bar or history
