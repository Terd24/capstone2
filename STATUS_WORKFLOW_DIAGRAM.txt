RULES:
-----
✅ Can only move forward in workflow
❌ Cannot go backwards
❌ Cannot skip steps
✅ Final states (Claimed/Declined) are locked


EXAMPLE SCENARIOS:
-----------------

Scenario 1: Normal Flow
------------------------
1. Student requests Form137 → Status: Pending
2. Registrar approves → Status: Approved (balance created)
3. Document is ready → Status: Ready to Claim
4. Student claims → Status: Claimed (locked)

Scenario 2: Declined Request
-----------------------------
1. Student requests document → Status: Pending
2. Registrar declines → Status: Declined (locked)
3. No further changes possible

Scenario 3: What User Sees
---------------------------
When status is "Pending":
┌─────────────────────┐
│ Pending        ▼    │ ← Dropdown is enabled
├─────────────────────┤
│ Pending (selected)  │
│ Approved            │
│ Declined            │
└─────────────────────┘

When status is "Approved":
┌─────────────────────┐
│ Approved       ▼    │ ← Dropdown is enabled
├─────────────────────┤
│ Approved (selected) │
│ Ready to Claim      │
└─────────────────────┘

When status is "Claimed":
┌─────────────────────┐
│ Claimed        ▼    │ ← Dropdown is DISABLED
├─────────────────────┤
│ Claimed (selected)  │
└─────────────────────┘
