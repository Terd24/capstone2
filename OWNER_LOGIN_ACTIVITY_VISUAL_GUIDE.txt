                              USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

SCENARIO 1: Find all active employee sessions
  1. Go to Dashboard
  2. In "Today's Logins" section
  3. Select User Type: "Employee"
  4. Look for "Active 🟢" in Logout column

SCENARIO 2: Check which teachers haven't logged in
  1. Scroll to "Not Logged In Today - Employees"
  2. Select Role: "Teacher"
  3. View filtered list

SCENARIO 3: Search for specific student
  1. In "Today's Logins" section
  2. Select User Type: "Student"
  3. Type student ID or name in Search box

SCENARIO 4: Monitor parent engagement
  1. Scroll to "Not Logged In Today - Students & Parents"
  2. Select Type: "Parents"
  3. View list of parents who haven't logged in
