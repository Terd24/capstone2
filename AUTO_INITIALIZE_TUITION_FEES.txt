AUTO-INITIALIZE TUITION FEE SYSTEM
====================================

OVERVIEW:
---------
Instead of manually adding each grade level, track, term, and school year combination,
the system can now AUTO-POPULATE all possible combinations with ₱0.00 fees.

Owner only needs to EDIT the prices, not ADD manually!

HOW TO USE:
-----------

METHOD 1: Click Button in Dashboard
1. Login as Owner
2. Go to Dashboard → Tuition Fees
3. Click "🔄 Initialize All Fees" button (green button)
4. New tab opens showing initialization results
5. Close tab and refresh dashboard
6. All fees now visible with ₱0.00

METHOD 2: Direct URL
1. Navigate to: http://localhost/onecci/OwnerF/initialize_tuition_fees.php
2. View results
3. Go back to dashboard

WHAT HAPPENS:
-------------
✓ Script checks existing records
✓ Only inserts MISSING combinations
✓ Skips existing records (safe to run multiple times)
✓ All new records have:
  - Tuition Fee: ₱0.00
  - Other Fees: ₱0.00
  - Total Fee: ₱0.00

AFTER INITIALIZATION:
---------------------
1. Go to Owner Dashboard → Tuition Fees
2. Expand school year (e.g., 2025-2026)
3. Filter by term if needed (1st or 2nd Semester)
4. See all grade levels with ₱0.00
5. Click edit button on each card
6. Update tuition fee and other fees
7. Save changes

ADDING MORE SCHOOL YEARS:
--------------------------
To add more school years (e.g., 2027-2028):
1. Edit: OwnerF/initialize_tuition_fees.php
2. Find: $school_years = ['2024-2025', '2025-2026', '2026-2027'];
3. Add: '2027-2028'
4. Run script again
5. Only new year combinations will be added

ADDING MORE STRANDS/COURSES:
-----------------------------
To add more strands (e.g., TVL):
1. Edit: OwnerF/initialize_tuition_fees.php
2. Find: $grade_structures array
3. Add new entries:
   ['grade_level' => 'Grade 11', 'academic_track' => 'TVL'],
   ['grade_level' => 'Grade 12', 'academic_track' => 'TVL'],
4. Run script again

TECHNICAL DETAILS:
------------------
File: OwnerF/initialize_tuition_fees.php
Database: tuition_fee_structure table
Insert Method: ON DUPLICATE KEY UPDATE (prevents duplicates)
Check Method: SELECT before INSERT (skips existing)

SAFETY:
-------
✓ Can be run multiple times
✓ Won't create duplicates
✓ Won't overwrite existing prices
✓ Only adds missing combinations
✓ Shows summary of what was added
