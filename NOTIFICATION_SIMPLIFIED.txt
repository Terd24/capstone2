NOTIFICATION SYSTEM SIMPLIFIED
==============================

CHANGE MADE:
------------
Removed the blue auto-notification that appeared when Owner approved/rejected archive requests.

WHAT WAS REMOVED:
-----------------
❌ Blue notification: "Login Logs Archive Approved"
❌ Red notification: "Login Logs Archive Rejected"

These notifications appeared automatically 2-10 seconds after Owner took action.

WHAT REMAINS:
-------------
✅ Green notification: "Request Submitted" (when SuperAdmin submits the request)
✅ Button automatically re-enables when Owner approves (within 2 seconds)
✅ "Request pending approval from Owner" message shows/hides automatically

USER EXPERIENCE NOW:
--------------------
1. SuperAdmin submits archive request
   → Green notification: "Request Submitted"
   → Button disables, shows "Request pending approval from Owner"

2. Owner approves/rejects the request
   → NO notification appears
   → Button automatically re-enables within 2 seconds
   → "Pending" message disappears

3. SuperAdmin can submit a new request immediately

BENEFITS:
---------
✓ Cleaner, less intrusive interface
✓ No duplicate notifications
✓ Button behavior is clear and automatic
✓ User can see status by checking if button is enabled/disabled
